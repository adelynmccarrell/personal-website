# Personal portfolio website

Four-page static site for GitHub Pages.

## Before publishing
1. Update the LinkedIn URL in `contact.html`.
2. Create a Google Form, set access to external respondents, then replace the placeholder card in `contact.html` with the iframe code in the HTML comment.
3. Check all wording for accuracy.
4. Publish via GitHub repository Settings → Pages → Deploy from a branch → main / root.
5. Test the published site and Google Form in a private/incognito browser window.
